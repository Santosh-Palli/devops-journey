As the next step i have learned about the File Permissions in Linux which are very crutial.
I have done a hand's on exercices by 
Creating some new files using "touch file_name" command.
Checking for file permissions using the "ls -l" command.
Changing the file permissions using the "chmod value file_name" command.
//Here 'value' refers to 4-read, 2-write, 1-execute and should be given as ex: 642 in which 6-refers to user/owner, 4-refers to a group and 2-refers to others.
Changing the ownership of the file using "chown owner_name file_name" command.
